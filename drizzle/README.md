# Migrations V1 — legado

Este diretório preserva as migrations e metadados históricos da V1 exclusivamente
para consulta técnica. A configuração ativa do Drizzle está em `../drizzle.config.ts`
e aponta para `../drizzle-v2`; portanto, estes arquivos não participam da evolução
nem da execução das migrations V2.

Não use este diretório para aplicar migrations no banco V2.
